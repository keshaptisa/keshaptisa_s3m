# 3D Mesh Quality Control

Решение задачи **AI Journey 2026: 3D Mesh Quality Control**. Для каждого 3D-меша модель предсказывает 10 типов дефектов и метку `quality` («объект без дефектов»).

**Лучший результат на лидерборде: 15.541.** Вложенная кросс-валидация этой сборки: **14.855**.

Финальный ансамбль объединяет три модели с разными бэкбонами и разрешениями: `vitb336`, `dino448_s2` и `v5_224`. Вероятности смешиваются в логит-пространстве с весами `0.75 / 1.00 / 0.50`, после чего применяются пороги и согласование меток.

## Ключевые точки

**Шаги 2 -> 8.** Полтора дня перебора улучшений модели не дали прироста, а один приём постобработки улучшил результат. Согласование с тождеством `quality = 1 <=> нет дефектов` было найдено при сравнении с решением напарницы.

**Шаг 9.** Единственный крупный скачок, `+0.54`, дал ансамбль трёх разных комбинаций «бэкбон + разрешение». Корреляция ошибок источников составляла `0.77-0.84`.

**Шаг 11.** Расхождение с результатом 15.541 на 95 ячеек объяснилось двумя объектами покрытия. Маска строилась по условию «нет `NaN`» вместо «фолд загружен». Из-за сдвига порогов 86 пограничных объектов изменили класс.

## Что работало

- ансамбль разнородных моделей с подобранными весами;
- разрешения 336 и 448 вместо 224;
- согласование `quality` и дефектов;
- глобальные веса правила вместо отдельных весов по классам.

## Что не сработало

- DINOv3: 13.79 против 14.24 у DINOv2;
- EVA-02: два фолда из пяти схлопнулись;
- второй уровень целиком: 14.317 против 14.329 у чистого CNN-бленда;
- пороги по целевой доле;
- soft-F1;
- спектр Лапласа;
- отдельная модель для `quality`.

## Валидация

Основная внутренняя оценка — вложенная кросс-валидация: решающее правило настраивается на четырёх фолдах и проверяется на пятом. Это позволяет оценивать правило постобработки без подгонки на тех же OOF-предсказаниях.

Метрика соревнования:

```text
10 * F1(quality) + 10 * F1_weighted(10 дефектов)
```

> Некоторые ноутбуки используют кэши, датасет и артефакты обучения из Google Drive. Пути и доступность весов следует проверить перед полным воспроизведением.
