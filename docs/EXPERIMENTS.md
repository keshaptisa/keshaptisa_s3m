## Диагностики

**Бутстрап шума лидерборда.** Одна и та же модель на случайных подвыборках
по 669 объектов: **14.404 ± 0.384**, 95% интервал [13.61, 15.15].
Вероятность разницы ≥ 0.46 просто по выборке — 55%.

**AUC «train против test»** по 235 признакам: **0.502**. Выборки статистически
неразличимы, гипотеза о сдвиге распределений отвергнута.

**Метрика на «тестоподобных» объектах** (верхние 25% по вероятности принадлежать
тесту): 14.461 против 14.367 на остальных. Разница +0.094, то есть ноль.

**Сжатие разброса вероятностей** OOF против теста: медиана 0.98. Механизма,
на который рассчитывала квантильная коррекция порогов, нет.

**Устойчивость выбора правила** по пяти независимым разбиениям:

| вариант | среднее | std |
|---|---|---|
| только глобальные веса | 14.299 | 0.011 |
| как в v5 (по-классовые, min_sup=300) | 14.276 | 0.020 |
| грубая сетка весов | 14.271 | 0.034 |

**Состав бленда** по пяти разбиениям:

| состав | среднее | std |
|---|---|---|
| только CNN | 14.329 | 0.014 |
| все пять источников | 14.317 | 0.007 |
| без POWERSET | 14.279 | 0.018 |
| CNN + GBM + DINO | 14.176 | 0.009 |

Второй уровень не даёт ничего измеримого.

**Методы предсказания `quality`**, вложенная оценка F1:

| метод | F1 |
|---|---|
| головы всех источников (логит-среднее) | 0.7233 |
| голова CNN | 0.7165 |
| логрегрессия на всех вероятностях | 0.7104 |
| LightGBM под quality | 0.7088 |
| powerset P(все нули) | 0.7031 |
| Π(1−p) с изотонной калибровкой | 0.7012 |
| мягкое правило Π(1−p) | 0.6910 |
| LightGBM + геометрия | 0.6842 |

Все «умные» методы проиграли простой голове. Причина: 35% ложных «хороших»
объектов имеют `lowpoly`, 31% `simple`, 28% `noisy` — ошибки `quality` производны
от детекции дефектов и отдельно не чинятся.
